Catat Transaksi Baru

Masukkan alamat URL web-app dari deployment Google Apps Script Anda untuk mengaktifkan sinkronisasi awan.

Simpan otomatis di cloud
  1. Buka lembar Google Sheets Anda.
  2. Klik Extensions (Ekstensi) > Apps Script.
  3. Tempelkan kode Apps Script yang Anda buat.
  4. Klik Deploy > New Deployment.
  5. Ubah jenis deploy ke Web App, ubah akses ke Anyone.
  6. Salin URL hasil deploy tersebut, tempelkan di atas lalu klik Simpan URL.
