Kode di bawah ini dilengkapi dengan fungsi beautifySpreadsheet(). Ini akan membuat tab khusus bernama Dashboard 🌿 di Google Sheets Anda, lalu mendesainnya secara otomatis dengan skema warna Sage Green, formula instan, bar kemajuan, dan tabel yang super rapi!

Langkah 1: Salin Kode Google Apps Script Baru
  1. Buka spreadsheet Google Sheets Anda.
  2. Pilih menu Ekstensi → klik Apps Script.
  3. Hapus seluruh kode bawaan, lalu tempel kode di bawah ini.

function doPost(e) {
  try {
    var payload = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    
    // 1. Simpan Target Budget
    if (payload.budgets) {
      var budgetSheet = getOrCreateSheet(ss, "Budgets");
      budgetSheet.clear();
      budgetSheet.appendRow(["Akun", "Target Budget"]);
      for (var key in payload.budgets) {
        budgetSheet.appendRow([key, payload.budgets[key]]);
      }
    }
    
    // 2. Simpan Transaksi Keuangan
    if (payload.transactions) {
      var txSheet = getOrCreateSheet(ss, "Transactions");
      txSheet.clear();
      txSheet.appendRow(["ID", "Status", "Tanggal", "Deskripsi", "Nominal", "Akun", "Kategori"]);
      payload.transactions.forEach(function(t) {
        txSheet.appendRow([
          t.id, 
          t.checked ? "Lunas" : "Belum", 
          t.date, 
          t.detail, 
          t.nominal, 
          t.account, 
          t.category
        ]);
      });
    }
    
    // Auto-Format setelah data berhasil masuk
    beautifySpreadsheet();
    
    return ContentService.createTextOutput(JSON.stringify({ 
      status: "success", 
      message: "Sinkronisasi & Perapihan otomatis berhasil!" 
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ 
      status: "error", 
      message: err.toString() 
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var budgets = {};
    var transactions = [];
    
    var budgetSheet = ss.getSheetByName("Budgets");
    if (budgetSheet) {
      var budgetRows = budgetSheet.getDataRange().getValues();
      for (var i = 1; i < budgetRows.length; i++) {
        budgets[budgetRows[i][0]] = Number(budgetRows[i][1]) || 0;
      }
    }
    
    var txSheet = ss.getSheetByName("Transactions");
    if (txSheet) {
      var txRows = txSheet.getDataRange().getValues();
      for (var j = 1; j < txRows.length; j++) {
        transactions.push({
          id: Number(txRows[j][0]) || Date.now(),
          checked: txRows[j][1] === "Lunas",
          date: txRows[j][2],
          detail: txRows[j][3],
          nominal: Number(txRows[j][4]) || 0,
          account: txRows[j][5],
          category: txRows[j][6]
        });
      }
    }
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      budgets: Object.keys(budgets).length > 0 ? budgets : null,
      transactions: transactions.length > 0 ? transactions : null
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ 
      status: "error", 
      message: err.toString() 
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

// FUNGSI AUTO-FORMAT PREMIUM SAGE GREEN
function beautifySpreadsheet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  
  // Ambil atau buat lembar-lembar data
  var txSheet = getOrCreateSheet(ss, "Transactions");
  var budgetSheet = getOrCreateSheet(ss, "Budgets");
  var dashSheet = getOrCreateSheet(ss, "Dashboard 🌿");
  
  // Pastikan susunan sheet rapi
  ss.setActiveSheet(dashSheet);
  ss.moveActiveSheet(1); // Taruh Dashboard di urutan pertama
  
  // === STYLE TAB TRANSAKSI ===
  txSheet.getRange("A1:G1").setBackground("#4c5c51").setFontColor("#ffffff").setFontWeight("bold").setHorizontalAlignment("center");
  txSheet.getRange("A:A").setHorizontalAlignment("center");
  txSheet.getRange("B:C").setHorizontalAlignment("center");
  txSheet.getRange("E:E").setNumberFormat("Rp#,##0");
  txSheet.setColumnWidths(1, 7, 120);
  txSheet.setFrozenRows(1);
  txSheet.showGridlines();
  
  // === STYLE TAB BUDGETS ===
  budgetSheet.getRange("A1:B1").setBackground("#4c5c51").setFontColor("#ffffff").setFontWeight("bold").setHorizontalAlignment("center");
  budgetSheet.getRange("B:B").setNumberFormat("Rp#,##0");
  budgetSheet.setColumnWidths(1, 2, 140);
  budgetSheet.setFrozenRows(1);
  budgetSheet.showGridlines();

  // === RANCANG TAB DASHBOARD 🌿 (Cermin dari spreedsheet.jpeg) ===
  dashSheet.clear();
  dashSheet.showGridlines(false); // Sembunyikan garis bawaan untuk tampilan dashboard modern
  
  // Judul Besar Dashboard
  dashSheet.getRange("B2:H2").merge()
    .setValue("🌿 SAGE FINANCE - LIVE FINANCIAL DASHBOARD 🌿")
    .setBackground("#e6ede8")
    .setFontColor("#2b342e")
    .setFontSize(13)
    .setFontWeight("bold")
    .setHorizontalAlignment("center")
    .setVerticalAlignment("middle");
  
  dashSheet.setRowHeight(2, 35);
  
  // Banner Total Pengeluaran
  dashSheet.getRange("B4:D4").merge().setValue("Total Pengeluaran Bulan Ini ->").setFontWeight("bold").setFontColor("#617568").setHorizontalAlignment("right");
  dashSheet.getRange("E4:H4").merge().setFormula("=SUM(Transactions!E2:E)").setNumberFormat("Rp#,##0").setFontSize(14).setFontWeight("bold").setFontColor("#b91c1c").setHorizontalAlignment("left");
  dashSheet.getRange("B4:H4").setBackground("#f4f7f5");
  dashSheet.setRowHeight(4, 28);
  
  // Label Section 1: Alokasi Budget Akun (Kiri)
  dashSheet.getRange("B6").setValue("AKUN").setFontWeight("bold").setBackground("#cfded4").setFontColor("#3e4b42").setHorizontalAlignment("center");
  dashSheet.getRange("C6").setValue("Cash").setFontWeight("bold").setBackground("#cfded4").setFontColor("#3e4b42").setHorizontalAlignment("center");
  
  dashSheet.getRange("B7").setValue("Budget").setFontWeight("semibold");
  dashSheet.getRange("C7").setFormula("=IFERROR(VLOOKUP(C6, Budgets!A2:B, 2, FALSE), 0)").setNumberFormat("Rp#,##0");
  
  dashSheet.getRange("B8").setValue("Expenses").setFontWeight("semibold");
  dashSheet.getRange("C8").setFormula("=SUMIF(Transactions!F2:F, C6, Transactions!E2:E)").setNumberFormat("Rp#,##0");
  
  dashSheet.getRange("B9").setValue("Sisa Budget").setFontWeight("semibold");
  dashSheet.getRange("C9").setFormula("=C7-C8").setNumberFormat("Rp#,##0").setFontColor("#047857").setFontWeight("bold");
  
  // Rapikan kotak Budget (B6:C9)
  dashSheet.getRange("B6:C9").setBorder(true, true, true, true, true, true, "#aabaaf", SpreadsheetApp.BorderStyle.SOLID);
  
  // Label Section 2: Portfolio Ringkasan (Kanan)
  dashSheet.getRange("E6:F6").merge().setValue("PORTOFOLIO STATUS").setFontWeight("bold").setBackground("#cfded4").setFontColor("#3e4b42").setHorizontalAlignment("center");
  
  dashSheet.getRange("E7").setValue("Total Semua Uang").setFontWeight("semibold");
  dashSheet.getRange("F7").setFormula("=SUM(Budgets!B2:B)").setNumberFormat("Rp#,##0");
  
  dashSheet.getRange("E8").setValue("% Teralokasikan").setFontWeight("semibold");
  dashSheet.getRange("F8").setFormula("=IF(F7>0, E4/F7, 0)").setNumberFormat("0.0%");
  
  dashSheet.getRange("E9").setValue("% Sisa").setFontWeight("semibold");
  dashSheet.getRange("F9").setFormula("=1-F8").setNumberFormat("0.0%");
  
  // Rapikan kotak Portofolio (E6:F9)
  dashSheet.getRange("E6:F9").setBorder(true, true, true, true, true, true, "#aabaaf", SpreadsheetApp.BorderStyle.SOLID);
  
  // Kolom Lebar Agar Rapi
  dashSheet.setColumnWidth(1, 40);
  dashSheet.setColumnWidth(2, 140);
  dashSheet.setColumnWidth(3, 140);
  dashSheet.setColumnWidth(4, 50);
  dashSheet.setColumnWidth(5, 140);
  dashSheet.setColumnWidth(6, 140);
  dashSheet.setColumnWidth(7, 140);
  dashSheet.setColumnWidth(8, 140);
  
  // Tambah petunjuk interaktif di Dashboard
  dashSheet.getRange("B11:F11").merge()
    .setValue("💡 Info: Gunakan sel C6 (tulis manual 'Cash', 'E-wallet', atau 'BNI') untuk melihat sisa budget per akun.")
    .setFontStyle("italic").setFontColor("#839689").setFontSize(9);
}

function getOrCreateSheet(ss, name) {
  var sheet = ss.getSheetByName(name);
  if (!sheet) {
    sheet = ss.insertSheet(name);
  }
  return sheet;
}

// MEMBUAT MENU DI GOOGLE SHEETS UNTUK MERAPIKAN MANUAL KAPAN SAJA
function onOpen() {
  var ui = SpreadsheetApp.getUi();
  ui.createMenu('🌿 Sage Finance')
      .addItem('Rapikan Spreadsheet (Auto-Format)', 'beautifySpreadsheet')
      .addToUi();
}
Langkah 2: Publikasikan Ulang sebagai Aplikasi Web
  1. Klik ikon disket (**Simpan**).
  2. Klik **Terapkan** (*Deploy*) → pilih **Kelola Penerapan** atau **Penerapan Baru**.
  3. Pilih jenis penerapan: **Aplikasi Web** (*Web App*).
  4. Wajib disetel:
    • Jalankan sebagai: **Saya**
    • Siapa yang memiliki akses: **Siapa saja** (*Anyone*)
  5. Klik **Terapkan**, lalu pastikan Anda menyalin URL Deployment Web App baru yang berakhiran `/exec`.
Langkah 3: Jalankan "Rapikan" Langsung Dari Spreadsheet Anda

Sekarang di dalam file Google Sheets Anda akan muncul menu baru di bar atas bernama 🌿 Sage Finance. Klik menu tersebut lalu pilih Rapikan Spreadsheet (Auto-Format) untuk langsung mengaktifkan desain cantiknya secara instan!
